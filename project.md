# Система учёта сотрудников организации

Веб-приложение для ведения, редактирования и учёта сотрудников компании с сохранением данных в формате XML.

---

## 🛠 Стек технологий

- **Фронтенд:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Бэкенд:** Java (Встроенный HTTP-сервер `com.sun.net.httpserver`, DOM XML Parser)
- **Хранилище данных:** XML (`data/data.xml`)

---

## 📁 Структура проекта

```text
├── backend/
│   └── Server.java          # Локальный HTTP-сервер на Java (REST API + работа с XML)
├── data/
│   └── data.xml             # База данных сотрудников в формате XML
├── css/
│   └── style.css            # Стили оформления интерфейса и бейджей
├── js/
│   └── main.js              # Логика фронтенда (REST-запросы, валидация, модальные окна)
├── index.html               # Главная страница пользовательского интерфейса
├── .gitignore               # Исключения сборки Git
└── README.md                # Документация проекта


Запуск сервера:  из командной строки корневой директории проекта: javac backend/Server.java
java -cp backend Server
