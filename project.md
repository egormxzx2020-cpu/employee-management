# Система кадрового учёта (HR-панель)

Веб-приложение для кадровика, позволяющее вести учёт персонала, отслеживать статусы и управлять данными сотрудников организации.

---

## Что входит в карточку сотрудника
* **Личные данные:** ФИО, дата рождения, адрес проживания.
* **Документы и связь (ввод строго по маске):**
  * Паспорт РФ (`0000 000000`)
  * Телефон (`+7 (000) 000-00-00`)
* **Рабочие данные:** отдел, должность, зарплата, дата приёма.
* **Статус:** работает / уволен.

---

## Возможности системы

1. **Сводная таблица:**
   * Просмотр всех сотрудников в едином списке.
   * Наглядный статус: активные сотрудники и метка «Уволен».
2. **Поиск и фильтры:**
   * Быстрый поиск по ФИО.
   * Фильтрация списка по отделам и должностям.
3. **Управление кадрами:**
   * Добавление нового сотрудника через удобную форму.
   * Редактирование данных действующих сотрудников.
4. **Увольнение сотрудников:**
   * Сотрудник не удаляется из базы и остаётся в таблице.
   * Получает визуальную метку **«Уволен»**.
   * Для него навсегда блокируется возможность изменения данных.

---

## Состав проекта

* **Frontend:**
  * Таблица сотрудников со статусами и кнопками действий.
  * Верхняя панель с фильтрами и поиском.
  * Всплывающие окна для добавления и изменения данных.
  * Маски для корректного ввода телефона и паспорта.
* **Backend:**
  * Сервер для обработки запросов (сохранение, обновление, увольнение).
  * База данных для надёжного хранения информации об отделах, должностях и сотрудниках.
